# FinSight AI - Next.js Frontend

FinSight AI frontend built with Next.js (App Router), Tailwind CSS, and Recharts.

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) with your browser to see the result.

## Available Scripts

- `npm run dev`: Starts the Next.js development server on port 5173 (matching the default backend CORS origin).
- `npm run build`: Builds the application for production.
- `npm run start`: Starts the Next.js production server.
